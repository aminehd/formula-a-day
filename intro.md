# a formula a day

[jaxvis](https://github.com/aminehd/jaxvis) animates a JAX function by walking its jaxpr, so every frame is a real intermediate value and not a drawing of one. Annotate the function, run it, get the clip.

One formula a day, published when it turns out well.

If you want to see more randomly generated things — shapes, flows and clouds made for no reason at all — [they are all on this page](fun.html).
