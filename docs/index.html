a formula a day

I made a framework for JAX visualisation where you can annotate your JAX-compatible function with it, and after it runs it generates a graph with the output of each intermediate operation that JAX generated. There is also another visualizer, which visualizes the transformation that happens to the function's input when the function is applied. You can think about grad as one such transformation.

I think seeing these formulas can be very helpful in learning them, and the generated images can be another learning channel for multimodal models or for agents to "see" what equations look like.

On this website, I am gonna experiment with different functions each day and publish if they turned out alright. Btw, to generate the images, I just need to annotate them with jaxvis.draw.

What a matrix does to a vector

$y = Mx$ is $n^2$ little multiplications, and then they are added up and thrown away. The input does not show them. The output does not show them. So the one question you actually want answered about a linear map — which input entry was responsible for which part of the output? — is invisible in both vectors.

It lives in the $n^2$ numbers $M_{ij}x_j$. One per wire.

How to read these. Inputs are the squares along the bottom, outputs the squares along the top, and there is one narrow link for every non-zero entry of $M$. A pulse travels each link from the entry that sent the contribution to the entry that receives it. Every link starts at its own random moment, so you see individual contributions landing rather than one curtain coming down — and the output squares only take their colour as their pulses arrive.

Colour is value, on one scale shared by the squares and the wires, symmetric about zero. The middle of the palette means nothing here.

import jax.numpy as jnp
import numpy as np
import jaxvis
import fad

fad.day(__file__)

n = 8
i = jnp.arange(n)
x = jnp.asarray([1.0, 2.0, 1.5, 3.0, 0.8, 2.4, 1.2, 2.8])

A running total

$$M_{ij} = [\,i \ge j\,]$$

Output $0$ gets one wire, output $7$ gets eight. The fan widening from left to right is the prefix sum — and it is also the reason nobody computes one this way: the picture has $O(n^2)$ wires in it.

jaxvis.impact(i[:, None] >= i[None, :], x, name="running_total")

Local averaging

$$M_{ij} = \tfrac{1}{3}\,[\,|i - j| \le 1\,]$$

Three wires per output and all of them short. Nothing travels far, which is the whole character of a local operator — and the reason a convolution is cheap where the running total was not.

jaxvis.impact((jnp.abs(i[:, None] - i[None, :]) <= 1) / 3.0, x,
              name="local_average")

A permutation

$$M_{ij} = [\,i + j = n - 1\,]$$

Reversal. Eight wires, every one crossing the middle exactly once, nothing mixing and nothing lost. One wire in and one wire out of each square is what it means for a matrix to only move numbers.

jaxvis.impact((i[:, None] + i[None, :] == n - 1) * 1.0, x,
              name="permutation")

A cyclic shift

$$M_{ij} = [\,j = (i + 1) \bmod n\,]$$

A permutation again, but a lazy one: seven wires lean one step over and the eighth wraps all the way back across the frame. That one long wire is the entire content of the word cyclic.

jaxvis.impact((i[None, :] == (i[:, None] + 1) % n) * 1.0, x, name="shift")

A difference

$$M_{ij} = [\,i = j\,] - [\,i - j = 1\,]$$

Two wires per output carrying opposite signs, so the colours split to either side of the palette's middle. Every square both sends and cancels — which is what makes this the discrete derivative.

D = (jnp.where(i[:, None] == i[None, :], 1, 0)
     + jnp.where(i[:, None] - i[None, :] == 1, -1, 0))

jaxvis.impact(D, x, name="difference")

A learned weight matrix

$$M_{ij} \sim \mathcal{N}(0, 1)$$

No structure at all. Every input reaches every output, the signs go both ways, and contributions that cancel arrive at the same square from opposite ends of the palette. This is what one layer of a trained network looks like, and why reading its weights one entry at a time tells you nothing.

W = jnp.asarray(np.random.default_rng(7).normal(size=(n, n)) / 2.4)

jaxvis.impact(W, x, name="dense", spread=0.62)

Try it

Every clip on this page is one line. The matrix can be anything, and it does not have to be square:

import jaxvis
jaxvis.impact(M, x, name="mine")

The knobs: spread for how staggered the starts are, travel for how fast a pulse crosses, lattice for how visible the unlit wiring is, palette, and seed for a different random order.

One dimension

A point cloud shows you where things go. A curve shows you what a function is. Same machinery underneath: every line below is one jaxpr, drawn one primitive at a time, so each frame is a real intermediate value and not an illustration of one.

Each clip starts as a flat line at zero, rises into the input $y = x$, and from there every bend is one more primitive. The caption under the frame names the one you are looking at.

The window is fixed, so a curve that leaves it is pinned dimly to the edge rather than disappearing -- an exponential on its way up is still somewhere.

import jax.numpy as jnp
import jaxvis
import fad

fad.day(__file__)

x = jaxvis.rail(-6.0, 6.0, 500)

The squash

$$\sigma(x) = \frac{1}{1 + e^{-x}}$$

Four primitives: negate, exponentiate, add one, divide. The straight sloping line early on is $-x$ -- negation is a reflection, and a reflected straight line is still a straight line. Then the exponential blows up off the top of the frame, and the division folds it back into a window one unit tall.

@jaxvis.draw(x, **jaxvis.curve(x, ylim=(-0.35, 1.35), palette="vapor"))
def sigmoid(p):
    return 1.0 / (1.0 + jnp.exp(-p))

The soft hinge

$$\operatorname{softplus}(x) = \log(1 + e^{x})$$

The same exponential, bent the other way. The log is what turns a wall into a hinge.

@jaxvis.draw(x, **jaxvis.curve(x, ylim=(-1.0, 6.5), palette="ultra",
                               fill=0.08))
def softplus(p):
    return jnp.log1p(jnp.exp(p))

GELU

$$\operatorname{gelu}(x) \approx \tfrac{1}{2}x\left(1 + \tanh!\left[\sqrt{\tfrac{2}{\pi}}\left(x + 0.044715x^{3}\right)\right]\right)$$

The activation inside almost every transformer you will ever profile. It is a sigmoid-shaped gate multiplied back onto $x$ — and the dip just left of zero, the part a ReLU does not have, arrives in the very last multiply.

@jaxvis.draw(x, **jaxvis.curve(x, ylim=(-1.5, 6.5), palette="bloom"))
def gelu(p):
    inner = 0.7978845608 * (p + 0.044715 * p ** 3)
    return 0.5 * p * (1.0 + jnp.tanh(inner))

A square out of sines

$$f(t) = \sin t + \tfrac{1}{3}\sin 3t + \tfrac{1}{5}\sin 5t + \tfrac{1}{7}\sin 7t$$

On a fixed window the corrections are finally visible: each harmonic arrives at full height, gets divided down, and settles into the corners. A window that rescales itself every frame would hide exactly that — the division would animate as nothing happening at all.

s = jaxvis.rail(-jnp.pi, jnp.pi, 500)


@jaxvis.draw(s, **jaxvis.curve(s, ylim=(-1.45, 1.45), palette="vapor"))
def square_wave(p):
    y = jnp.sin(p)
    y = y + jnp.sin(3.0 * p) / 3.0
    y = y + jnp.sin(5.0 * p) / 5.0
    return y + jnp.sin(7.0 * p) / 7.0

The bell

$$y = e^{-x^{2}/2}$$

Square, negate, halve, exponentiate. The parabola that falls off the bottom of the frame comes back as the only bounded shape in the file.

@jaxvis.draw(x, **jaxvis.curve(x, ylim=(-0.3, 1.25), palette="ember",
                               fill=0.10))
def bell(p):
    return jnp.exp(-(p ** 2) / 2.0)

Ringing down

$$y = e^{-t/3}\sin 4t$$

A sine multiplied by a decay. The envelope never gets drawn — it is the one multiply at the end, and you see it as the whole curve being pulled toward the axis from the right.

r = jaxvis.rail(0.0, 12.0, 500)


@jaxvis.draw(r, **jaxvis.curve(r, ylim=(-1.15, 1.15), palette="ultra"))
def ring_down(p):
    return jnp.exp(-p / 3.0) * jnp.sin(4.0 * p)
